# Niloy Mart

Niloy Mart is a full-stack e-commerce web application developed using the MERN Stack. Users can browse products, create accounts, add products to their cart, place orders, and view their order history.

## Features

### User Features

- User registration and login
- Browse available products
- View product details
- Add and remove products from the cart
- Checkout and place orders
- View personal order history
- Protected user routes

### Admin Features

- Admin dashboard
- Manage products
- Manage customer orders
- Manage users

## Technologies Used

### Frontend

- React.js
- Vite
- JavaScript
- React Context API
- Axios
- CSS

### Backend

- Node.js
- Express.js
- JSON Web Token (JWT) Authentication
- REST API

### Database

- MongoDB
- Mongoose ODM
- MongoDB connection configured through the `MONGO_URI` environment variable
